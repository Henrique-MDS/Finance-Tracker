getData -> Função para pegar um dado específico com base nos parametros enviados em forma de objeto
-> A variável "operation" é um breve resumo do que será buscado no banco. É utilizado para retornar um log, caso haja erro
para utilizar forneça o nome da tabela, um objeto contendo o nome do campo e o valor para inserir no WHERE e o ultimo argumento é um resumo do que voce está buscando no banco, observe o exemplo abaixo:
const categories = await getData(
    "Categories",
    { user_id: "101a0389-8f55-4467-afca-29bcc93a723a" },
    "Buscar todas as categorias"
);
get data retorna um objeto com essas propriedades:
type getDataInterface = {
    success: boolean;
    message: string;
    data?: any[];
    name?: string;
    email?: string;
    error?: any;
}
verifyEmail -> Função com uma regex para testar se o email é valido (apenas os caracteres, não envia token)
getUserLogin -> Pega as credenciais do usuario e faz uma consulta, se tiver grava o id no localStorage para poder entrar em rotas protegidas
notify -> aceita uma mensagem como parametro para exibir um popup na tela, pode ser de erro ou sucesso. ex: notify.error("Campos obrigatórios não preenchidos")
deleteData -> Funciona como a função getData, usando os mesmos parametros, mas delete o registro no banco de acordo com o parametro passado. ex:
const categories = await deleteData(
    "Categories",
    { user_id: "101a0389-8f55-4467-afca-29bcc93a723a" },
    "Deletar categoria do usuário"
);
get data retorna um objeto com essas propriedades:
type deleteDataInterface = {

getIntervalData -> Funciona para pegar dados dentro de um intervalo, podendo ser data, numero, etc. Para usar passe a tabela, valor1 e valor2, o campo que quer filtrar e a operaçaoa ex:
const response = await getIntervalData(
    "Transactions",
    "tran_date",
    firstDay.toISOString(),
    lastDay.toISOString(),
    "buscar valores dentro do mês atual"
);
lembrando que se usar data o supabase aceita só no formato usando toISOString
filterDespesaReceita -> funçao que filtra e devolve um objeto com as operaçoes separadas entre "Despesa" e "Receita". Só aceita um array de dados do tipo Transactions ex:
setFilteredType(filterDespesaReceita(transactions));

getMonthlySummary -> Funçao que chama outra funçao do postgre que retorna a balança das transaçoes mensais (receitas - despesas), retorna dados da balança separado pelos meses que existem transaçoes
const response = await getMonthlySummary(userId);
retorna algo como:
[
  { month: "Jan", receita: 186, despesa: 80 },
  { month: "Fev", receita: 250, despesa: 120 },
  { month: "Mar", receita: 300, despesa: 150 }
]
getCategoryTotals -> busca o valor total das categorias, seja em despesa ou receita. Para user passe o userId e o tipo (receita e despesa)
const response = await getCategoryTotals(
    userId,
    "Despesa"
)
retorna algo como:
{category_name: 'Alimentação', total: 2257}

returnMonth -> funçao que recebe um numero de 1 a 12 e retorna o mes do número correspondente
getReportData -> funçao para pegar dados dos relatórios. precisa de userid, tipo (receita/despesa), data incial e final. Se passar null em type ele traz todos
    id -> id da transacao
    user_id -> id do usuario
    "desc" -> desc da transacao
    type -> tipo
    value -> valor da transacao
    SUM(value) OVER () AS total_value -> valor da soma das transacoes do tipo
    tran_date -> data
