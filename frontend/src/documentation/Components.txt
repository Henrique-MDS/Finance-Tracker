RESUMECARD

Card exibido na página principal para resumo de valores
argumentos que devem ser enviados ao usar
title -> título
valor -> valor em dinheiro
desc -> descrição curta do resumo financeiro
emoji -> ícone para exibição
themeColor -> cor para texto e customizações em hexadecimal
bgColor -> cor de fundo do ícone em hexadecimal

SELECT_INPUTS
um input select com um label, suas propriedades são
label -> texto de exibiçao do input
placeholder -> placeholder para exibir no campo
option -> opções para selecionar (enviado em forma de array de strings)
onValueChange -> serve para pegar o valor do input ex: <SelectInput label="Tipo" placeholder="Tipo" options={["Receita", "Despesa"]} onValueChange={(e) => setType(e)}/>
value -> serve para colocar a variável de valor, caso precise resetar o campos depois com setValue("") ex: <SelectInput label="Categoria" placeholder="Categoria" options={catOptions} onValueChange={(e) => setCategory(e)} value={category}/>
ReportResumeCard -> cartão de resumo de finanças para o relatório, aceita titulo, valor, cor do valor, descrição ex:
<ReportResumeCard title={"Receitas"} value={"R$ 5.000,00"} themeColor={"#009966"}/>
